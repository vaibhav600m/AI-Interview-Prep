# AI Interview Prep 🤖

AI Interview Prep is an AI-powered web application designed to help students and job seekers prepare for technical interviews through interactive AI conversations and mock interviews.

## 🚀 Live Demo

# AI Interview Prep

🚀 **Live Demo:** https://ai-interview-prep-liart.vercel.app/

🔗 **Backend:** https://ai-interview-prep-xe2y.onrender.com

## ✨ Features

- 💬 AI-powered normal chat
- 🎯 Mock technical interviews
- 🔢 20-question mock interview
- 🎤 Voice input using speech recognition
- 🔊 AI voice responses
- ⚡ Adjustable AI speech speed
- 🌐 Automatic language detection
- 📊 Automatic interview evaluation
- ⭐ Overall interview score
- 💻 Technical Knowledge score
- 🧠 Problem Solving score
- 📚 Conceptual Understanding score
- 🗣️ Communication score
- ✅ Strengths identification
- ❌ Weakness identification
- 📚 Topics to improve
- 🎯 Personalized recommendations
- ✕ Closeable interview scorecard
- 🔄 Fresh interview session with cleared previous interview memory
- 📱 Responsive user interface
